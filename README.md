# 2d-midia

Arquivos de mídia dos posts do Instagram **@2drepres** (2D Representações Comerciais), servidos publicamente para a Instagram Graph API — que só aceita mídia por URL pública.

- `posts/AAAA-MM-DD_NN-slug.jpg|mp4` — arte final (JPEG ou MP4 H.264)
- `posts/…_capa.jpg` — capa de vídeo
- `posts/….txt` — legenda

Tudo aqui já é conteúdo destinado à publicação. Logos de marcas representadas aparecem como publicados em seus sites oficiais.
